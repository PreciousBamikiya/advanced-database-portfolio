# Project Overview

The Grand Horizon Hotel Reservation Management System is a database-driven solution designed to support the daily operations of a hotel. The system manages guest information, room allocation, reservations, payments, check-ins/check-outs, service requests, reporting, and administrative activities.

This portfolio demonstrates the application of advanced database concepts through a single case study implemented across five portfolio activities. The work covers relational database design, query optimisation, transaction management, NoSQL modelling, and distributed cloud database architecture.

# Cloud Database Deployment Report

## Introduction

The Grand Horizon Hotel Reservation Management System has been designed for deployment within a distributed cloud environment using Microsoft Azure SQL Database.

The aim is to support multiple hotel branches, improve availability, and increase scalability while maintaining data consistency.

---

## Cloud Platform

Microsoft Azure SQL Database was selected because it provides a fully managed relational database service with built-in security, backup, geo-replication, monitoring, and scalability features.

---

## Benefits

### High Availability

Azure maintains database availability through automatic failover and redundancy mechanisms.

### Automatic Backups

Regular backups reduce the risk of data loss.

### Scalability

Resources can be increased as reservation volumes grow.

### Security

Azure provides encryption at rest and in transit.

---

## Challenges

### Network Dependency

Cloud databases require reliable internet connectivity.

### Cost Management

Increasing storage and compute resources may increase operational costs.

### Data Privacy

Customer information must be protected through proper security controls.

---

## Conclusion

The Azure deployment model provides a scalable and resilient platform suitable for a growing hotel reservation business operating across multiple locations.
